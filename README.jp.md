## ゲーム概要

**Astra Floor** は、隔離された終末工業地帯を舞台に、迫り来る生体変異体「Zed」の大群を殲滅しながら生き延びるウェーブ制の3DサバイバルFPSです。

敵の撃破やウェーブクリアでクレジット（₡）を獲得し、ウェーブ間の補給ショップで武器・弾薬・アーマー・アイテムを強化・購入して装備を整えます。Wave 1〜6の猛攻を耐え抜き、Wave 7に君臨する最終ボス **Hans Volter** を撃破して脱出（ゲームクリア）を目指します。

FPSの王道であるキーボード・マウス操作を重視し、移動撃ち（ストレイフ射撃）、リコイルコントロール（射撃反動の制御）、スプリント回避、カタナによる薙ぎ払い近接戦、グレネードによる空間制圧、そして緻密なリソース管理が生存の鍵を握ります。

## 主な特徴

- **ブラウザ完結の本格3D FPS**  
  **Three.js** と **React 19 / vinext** により、追加のクライアントインストールやプラグインなしで、Webブラウザ上で直接高画質・高フレームレートの3Dアクションが動作します。
- **100% インメモリ・プロシージャルアセット生成**  
  銃器モデル、工業地帯の背景建築、変異敵の骨格・メッシュ、および128〜256pxのPBRテクスチャ群（アルベド・ノーマル・ラフネス）を起動時にメモリ上でプロシージャル（手続き型）生成。大容量の外部3Dモデルやテクスチャのダウンロード待機は一切ありません。
- **Web Audio API によるリアルタイム音響合成**  
  銃撃音（過渡スナップ音・銃口爆風・低音パンチ）、スナイパーライフルのボルト開閉音、ロケットの飛翔音と大爆発、弾丸の跳弾音、敵の呻き声、Hans Volterのメカニカルな音声や警告音に至るまで、すべてWeb Audio APIのオシレーター、ノイズバッファ、Biquadフィルター、マスターコンプレッサーによってリアルタイムに合成出力されます。
- **リアルなリコイルと精密射撃**  
  発砲ごとにカメラのピッチ（上下）とヨー（左右）へ強力な反動が加わります。**射撃を止めても照準は自動で元には戻りません。** プレイヤー自身のマウス引き下げ操作（リコイルコントロール）が必須です。全銃器およびロケット直撃において、ヘッドショット時は **3.0倍** の致命的ダメージを与えます。

## 操作方法と基本システム

### 操作キー一覧（PCキーボード・マウス専用）

| 操作 | キー / 入力 | 補足 |
|---|---|---|

| **視点移動 / 照準** | `マウス` | ポインターロックによる視点操作・リコイル制御 |
| **射撃** | `左クリック` | 所持武器のセミオート / フルオート射撃 |
| **照準（ADS / スコープ）** | `右クリック長押し` | 弾の拡散と反動を抑制、スナイパーライフルは5倍スコープ展開 |
| **スプリント（ダッシュ）** | `左Shift` | スタミナ毎秒20消費（ADS中は使用不可） |
| **ジャンプ** | `Space` | 段差の乗り越え・敵攻撃の跳躍回避 |
| **リロード** | `R` | マガジン弾薬の再装填 |
| **武器切り替え** | `1` `2` `3` `4` | `1`: ハンドガン/G18C、`2`: アサルトライフル、`3`: スナイパーライフル、`4`: RPG-7 |
| **近接攻撃** | `V` | 通常殴り（42ダメ） / カタナ薙ぎ払い（110ダメ） |
| **グレネード投擲** | `G` | 放物線投擲。投擲から1.0秒後に爆発 |
| **Medical Kit使用** | `Q` | HPを50即時回復（クールダウン10秒、最大3個所持） |
| **ポーズ（一時停止）** | `Esc` | ポインターロック解除、戦闘・飛翔物・タイマーを一時停止 |
| **Waveクリア進行** | `Space` / `Enter` | リザルト画面からショップ画面へ移行 |
| **デバッグ設定パネル** | `F8` | タイトル画面限定。Wave 1〜7選択、所持金設定、HP下限設定 |

### 基本生存ルール

- **HPとアーマー**  
  HP最大値は **100**、ボディアーマー最大値は **100** です（両難易度共通）。受けたダメージは **アーマーが100%優先して吸収** し、アーマーが0になった超過分のみがHPに減少ダメージを与えます。
- **ウェーブクリア時の回復**  
  ウェーブ内の全敵を殲滅してクリアすると、HPが **100まで全回復** します。ただし、アーマー・弾薬・Medical Kit・グレネードは自動回復しないため、ショップで補給する必要があります。
- **スタミナシステム**  
  スプリント中はスタミナを **毎秒20消費** します。非スプリント時は **毎秒20回復** し、最大値は **100** です。ADS（右クリック照準）中はスプリントできません。
- **Medical Kit（`Q` キー）**  
  1個消費してHPを50回復します（上限100）。使用後は **10秒間のクールダウン** が発生し、クールダウン中は追加使用できません。クールダウンは戦闘中のみ進み、ポーズ中やショップ中は停止します。初期所持数は3個、最大所持数も3個です。
- **破片手榴弾（Frag Grenade / `G` キー）**  
  `G` キーで照準方向へ投擲します。壁や地面をバウンドし、**手を離れてから1.0秒後に起爆** します。爆発は **半径7.0m未満** に距離減衰を伴う大ダメージを与え、遮蔽物で防護されます。至近距離での爆発はプレイヤー自身も最大50の自爆ダメージを受けるため距離を保ちましょう。
- **弾の拡散とリコイル制御**  
  腰だめ撃ち（Hip-fire）は弾が散開します。右クリック長押しでサイト/スコープを覗き込む（ADS）ことで拡散率を大幅に抑えられます。連射時の反動は手動でマウスを引き下げることで補正します。

### 特殊な射撃メカニズム

- **SR-3のボルトアクション機構**  
  1発撃つごとに自動でスコープを下げ、約1.1秒かけてボルトを起こして排莢・装填します。ボルト操作中は武器持ち替えを行ってもスキップできません。弾倉が空になった場合はボルト操作が発生せず、即座にリロードへ移行できます。
- **RPG-7の弾道と直撃ヘッドショット**  
  ロケット弾は照準方向へ **60 m/s** で重力落下せず直線飛行します。敵・床・壁に着弾するか、飛翔後2.0秒で爆発します。敵の頭部（Head）に直接命中させた場合、直撃した敵にのみ **3.0倍のヘッドショットダメージ（最大1,800）** が与えられます（周囲の敵は通常の爆風ダメージ）。発射時に予備弾があれば自動でリロードを開始します。

## ショップ・経済システム

ウェーブをクリアすると、安全な **PREPARATION SHOP（補給ショップ）** が開きます。ショップには制限時間がありません。納得のいくまで戦備を整え、準備ができたら **NEXT WAVE**（Wave 7突入時は **FACE HANS VOLTER**）を押して出撃します。

### クレジット（₡）獲得

- **敵撃破報酬**：Zedを倒すごとに即時獲得（Clot: ₡65, Crawler: ₡55, Gorefast: ₡85, Bloat: ₡110, Scrake: ₡130, Husk: ₡160, Freshpound: ₡450, Hans Volter: ₡2,000）。
- **ウェーブクリア報酬**：Wave 1〜6クリア時に **₡250 + (ウェーブ番号 × ₡50)** を獲得。Wave 6クリア時は **₡550** を獲得します。

| **初期弾薬** | 12 / 48 *(装填・予備ともに満タン)* | 12 / 48 *(装填・予備ともに満タン)* |

| **初期装備** | H1 Service Pistol, Medkit 3個 | H1 Service Pistol, Medkit 3個 |
| **敵HP・攻撃力倍率** | 1.0倍 | 1.35倍 |
| **敵移動速度倍率** | 1.0倍 | 1.10倍 |
| **敵の出現頻度** | 通常 | 高頻度スポーン |

*※難易度リソースと上限の仕様について：*
- **初期リソース満タン開始**: 通常（Normal）・ハード（Hard）ともに、出撃時はHP（100）、アーマー（100）、初期ハンドガン弾薬（装填12/予備48）、Medical Kit（3/3）、グレネード（3/3）のすべてが満タンの万全な状態でスタートします。
- **仕様の変遷と現行仕様**: ゲーム仕様策定時には「Normal: アーマー上限50・グレネード上限3 / Hard: アーマー上限100・グレネード上限5」として設計されていましたが、最新の確定仕様書（`docs/game-rules.jp.md`、`docs/dev/dev-rules.jp.md`）および現行実装では、アーマー上限は両難易度共通で100（100%ダメージ吸収）、グレネード初期上限も両難易度共通で3個（ショップの弾薬ポーチ Ammo Pouch 購入で上限5個へ拡張）へと洗練・統一されています。

- **ウェーブ進行による敵強化**:
  ウェーブが1つ進むごとに、敵の基礎HP倍率が **+0.1**、移動速度倍率が **+0.045** 増加します：  
  $$\text{Enemy HP} = \text{Base HP} \times (1 + (\text{Wave} - 1) \times 0.1) \times \text{Difficulty Multiplier}$$  
  （計算式：`敵HP = 基本HP × (1 + (ウェーブ数 − 1) × 0.1) × 難易度倍率`）
- **ウェーブごとの敵総数**:
  - **Normal**: Wave 1: 9体, Wave 2: 12体, Wave 3: 15体, Wave 4: 18体, Wave 5: 21体（Freshpound 1体含む）, Wave 6: 24体（Freshpound 2体含む）, Wave 7: Hans Volter 1体。
  - **Hard**: Wave 1: スキップ, Wave 2: 24体, Wave 3: 30体, Wave 4: 36体, Wave 5: 42体（Freshpound 1体含む）, Wave 6: 48体（Freshpound 2体含む）, Wave 7: Hans Volter 1体。

### デバッグ設定パネル（`F8` キー）

タイトル画面で **`F8`** を押すと、開発・検証用のデバッグ設定パネルを開閉できます（戦闘中は誤操作防止のため無効化）。
- **開始Wave選択**: Wave 1〜7をワンクリックで選択可能（Wave 7を選択すると即座にHans Volterボス戦前哨へ直行）。
- **難易度切り替え**: Normal / Hard を即時切り替え。
- **所持クレジット設定**: 初期値 ₡20,000。`[-10k]` / `[+10k]` で10,000刻みの増減、および `[RESET]` ボタンで20,000に戻すことが可能。
- **HP下限設定（PREVENT DEATH / MIN HP 1）**: チェックを入れると、敵の攻撃・手榴弾の自爆・Hansの毒ガスなどあらゆる被ダメージを受けてもHPが1未満にならず、ゲームオーバーにならずに戦闘を継続検証可能。
- **直前ショップ（PREPARATION SHOP）**: どのWaveから開始しても、戦闘突入前に `WAVE 0N PREPARATION` ショップが開き、潤沢な資金で自由に装備を組んでからテスト出撃できます。

### 最終ボス：Hans Volter（Wave 7）

Wave 6をクリアすると、専用のボス戦 **Hans Volter** へ突入します。Hansは **12,000の固定HP** を持ち、取り巻きの雑魚敵は湧きません。Wave 6クリア後のショップで購入した装備・弾薬・消耗品を引き継いで戦います。

#### ボスのアクションと攻略法

- **二丁MKb42連射**  
  射程32m以内において、0.85秒の構え後、左右のライフルを交互に約2.4秒連射（1発5ダメージ、弾速80m/s）。プレイヤーの現在位置へ正確に狙い撃つため、コンクリート壁などの遮蔽物に身を隠すことが必須。
- **毒ガスグレネード（毒ガス）**  
  1.0秒の投擲動作後、緑色の毒ガス弾を2発（第3段階では3発）投擲。1.4秒後に起爆し、半径4.2mに6.0秒間残留するガス雲を生成。毎秒 **24 / 30 / 36 ダメージ**。重なりによる重複ダメージはないため、即座に緑のエリアから離脱する。
- **スーパーリープ（Super Leap Slash / 超大跳躍斬撃）**  
  最大 **25〜28m規模の長距離跳躍**（最大飛距離29m、踏み込み速度22〜33m/s、頂点高度約3.5m）を描いて頭上から急襲。半径3.5mに **30 / 34 / 38 ダメージ**。構え時のベクトルへ踏み込んで飛ぶため単純な後退（`S`）では捕まります。横方向へのステップ移動（`A` / `D`）または遮蔽物の裏へ隠れることで回避可能。
- **突進（高速タクティカルダッシュ）**  
  0.5秒の予兆から0.65秒間、速度18〜21.6m/sで高速突進・ダッシュ。一気に間合いを詰めるか、横方向へフェイント回避を行う。
- **エネルギー枯渇スタン（4秒間の脆弱スタン）**  
  Hansは100のエネルギーを持ち、時間経過（-1/秒）や各アクション（射撃: 18、ガス: 22、ダッシュ: 12、跳躍: 20）で消費します。エネルギーが0になると、実行中の行動完了後に **4.0秒間の機能停止スタン状態** に陥ります。**スタン中は受ける全ダメージが1.5倍に増加** します！スタン終了後、エネルギーが100に再充電されて戦闘を再開します。
- **行動フェーズ**:
  - **フェーズ1**（HP 65%超）：基本行動ローテーション、ガス2発。
  - **フェーズ2**（HP 65%以下）：移動・ダッシュ速度向上、ガス30 DPS、跳躍34ダメ。
  - **フェーズ3**（HP 30%以下）：狂暴化、ガス3発同時投擲、ガス36 DPS、跳躍38ダメ。

## 技術スタックとプロジェクト構成

- **フロントエンド / エンジン**: React 19, Next.js 15+ App Router, Vite 8, [vinext](https://github.com/cloudflare/vinext)
- **3Dグラフィックス**: Three.js (`r185`), Canvasプロシージャル生成PBRテクスチャ、インスタンスバッチング描画
- **音響エンジン**: Web Audio API（リアルタイムシンセシス、ノイズ過渡エンベロープ、オシレーター、コンプレッサー）
- **UI / スタイル**: Tailwind CSS v4, Lucide React
- **ビルド / 配布ランタイム**: Cloudflare Workers / Sites (`@cloudflare/vite-plugin`, Wrangler)

## セットアップと開発手順

### 前提条件

- **Node.js**: `>= 22.13.0`
- **パッケージマネージャー**: `npm`

### リポジトリのクローンと依存関係のインストール

```bash
git clone https://github.com/username/astrafloor.git
cd astrafloor
npm install
```

### ローカル開発サーバーの起動

Vite / vinext 開発サーバーを立ち上げます：

```bash
npm run dev
```

ブラウザで [http://localhost:3000](http://localhost:3000) を開き、画面をクリックしてポインターをロックするとゲームが開始されます。

### 自動テストの実行

Node.js 組み込みのテストランナーにより、全136件のユニットテスト（ゲーム進行、弾道判定、リコイル計算、ボスの状態遷移、音響生成など）を実行します：

```bash
npm test
```

### 型検査とプロダクションビルド

TypeScriptの型チェックと本番向けバンドルビルドを実行します：

```bash
# TypeScript型チェック（コード出力なし）
npx tsc --noEmit

# 本番ビルド（SSR, RSC, クライアントアセット, Cloudflare Workerの生成）
npm run build
```
