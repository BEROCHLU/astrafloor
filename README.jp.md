## ゲーム概要

**Astra Floor** は、PCのキーボード・マウス専用に設計された、シングルプレイヤー向けの3DゾンビサバイバルFPSです。  
プレイヤーは隔離された終末工業地帯を舞台に、迫り来る異能変異体「Zod」の大群を殲滅しながら生き延びるウェーブ制の戦闘に挑みます。各Waveで敵を全滅させてクリアし、Wave間の補給ショップで武器・弾薬・アーマー・消耗品を購入・強化して装備を整えます。Wave 1〜6の猛攻を耐え抜き、Wave 7に君臨する最終ボスを撃破するとゲームクリア（勝利）、HPが0になるとゲームオーバー（敗北）となります。

※セーブ機能はなく、ブラウザの再読み込みやリトライ、タイトルへ戻ると進行状況はリセットされます。

## 主な特徴

- **ブラウザ完結の本格3D FPS**  
  **Three.js** と **React 19 / vinext** により、追加のクライアントインストールやプラグインなしで、Webブラウザ上で直接高画質・高フレームレートの3Dアクションが動作します。
- **100% インメモリ・プロシージャルアセット生成**  
  銃器モデル、工業地帯の背景建築、変異敵の骨格・メッシュ、および128〜256pxのPBRテクスチャ群（アルベド・ノーマル・ラフネス）を起動時にメモリ上でプロシージャル（手続き型）生成。大容量の外部3Dモデルやテクスチャのダウンロード待機は一切ありません。
- **Web Audio API によるリアルタイム音響合成**  
  銃撃音（過渡スナップ音・銃口爆風・低音パンチ）、スナイパーライフルのボルト開閉音、ロケットの飛翔音と大爆発、弾丸の跳弾音、敵の呻き声、最終ボスのメカニカルな音声に至るまで、すべてWeb Audio APIのオシレーター、ノイズバッファ、Biquadフィルター、コンプレッサーによってリアルタイムに合成出力されます。
- **リアルなリコイルと精密射撃**  
  発砲ごとに強力な反動が加わります。プレイヤー自身のマウス引き下げ操作（リコイルコントロール）が必須です。全銃器およびロケット直撃において、ヘッドショット時は致命的ダメージを与えます。

## ゲームの基本システム・操作

FPS初心者がキーボード操作に慣れやすいよう、操作キーはシンプルかつ一般的なPC FPSと共通の配置を採用しています。

**ヘッドショットのダメージは通常の3倍です。** 銃弾およびRPG-7のロケット直撃で敵の頭部を狙うと、より効率よく敵を倒せます。

### 操作キー一覧（PCキーボード・マウス専用）

| 操作 | キー / 入力 | 概要 |
|---|---|---|
| **移動** | `W` `A` `S` `D` | 全方向の歩行移動 |
| **視点移動 / 照準** | `マウス` | ポインターロックによる視点操作・リコイル制御 |
| **射撃** | `左クリック` | 所持武器のセミオート / フルオート射撃 |
| **照準（ADS / スコープ）** | `右クリック長押し` | 弾の拡散と反動を抑制、スナイパーライフルは5倍スコープ展開 |
| **スプリント（ダッシュ）** | `左Shift` | スタミナ毎秒20消費（ADS中は使用不可） |
| **ジャンプ** | `Space` | 段差の乗り越え・敵攻撃の跳躍回避 |
| **リロード** | `R` | マガジン弾薬の再装填 |
| **武器切り替え** | `1` `2` `3` `4` | `1`: ハンドガン/G18C、`2`: アサルトライフル、`3`: スナイパーライフル、`4`: RPG-7 |
| **近接攻撃** | `V` | 通常殴り（初期） / カタナ薙ぎ払い（換装後） |
| **グレネード投擲** | `G` | 放物線投擲。投擲から1.0秒後に爆発（自爆あり） |
| **Medical Kit使用** | `Q` | HPを50即時回復（クールダウン10秒、最大3個所持） |
| **ポーズ（一時停止）** | `Esc` | ポインターロック解除、戦闘・タイマーを一時停止（**RESUME COMBAT** で再開） |
| **Waveクリア進行** | `Space` / `Enter` | リザルト画面から補給ショップ画面へ移行 |

### ゲームの進行と補給ショップ

1. **戦闘ウェーブ**：出現するZodの大群を全滅させるとウェーブクリアとなります。
2. **HPの自動全快**：ウェーブクリア時にHPが100まで全回復します。ただしアーマー・弾薬・消耗品は自動回復しません。
3. **補給ショップ（PREPARATION SHOP）**：
   - 敵の撃破やWaveクリア報酬としてクレジット（₡）を獲得します。
   - ウェーブ間は時間制限のないショップで、武器の購入、武器アップグレード、弾薬補給、アーマー、Medical Kit、グレネードを購入できます。
   - 購入した装備、強化段階、所持クレジット、残存する補給品はすべて次のWaveへ引き継がれます。
   - 準備が整ったら **NEXT WAVE**（Wave 7突入時は **FACE FINAL BOSS**）を押して出撃します。

## 生き延びるための基本戦術

- **アーマーによる完全防護**  
  HP・アーマーの上限は各100です。受けたダメージはアーマー残量が100%優先して吸収するため、アーマーを常に維持することが生存率を高めます。
- **移動撃ちと近接攻撃の活用**  
  移動しながら射撃するストレイフ撃ちや、移動中の近接攻撃（`V` キー）でゾンビの包囲を切り抜けるテクニックが不可欠です。
- **突進はスプリントでかわす**  
  敵に囲まれたり突進されたりした場合は、立ち止まらずにスプリント（`左Shift`）でかわしましょう。
- **精密なリコイル制御とヘッドショット**  
  ヘッドショットを積極的に狙いましょう。連射時の跳ね上がり反動は手動でマウスを引き下げて抑え込みます。
- **自己回復（Medical Kit）**  
  ピンチ時は `Q` キーでHPを50回復します（CT10秒、最大3個ストック）。
- **自爆への警戒**  
  破片手榴弾（`G`）やRPG-7のロケットは至近距離で爆発するとプレイヤー自身も大ダメージを受けます。距離を取るか遮蔽物を挟みましょう。

## 難易度設定

| 難易度 | 開始地点 | 初期所持金 | 特徴 |
|---|---|:---:|---|
| **Normal（通常）** | Wave 1 戦闘開始 | ₡500 | 標準的な敵HP・移動速度・出現頻度。FPS初心者〜中級者向け |
| **Hard（ハード）** | Wave 1クリア済みショップ（Wave 2出撃準備） | ₡2,000 | 敵のHP・移動速度・出現頻度が増加。初期資金で装備を整えて挑む上級者向け |

※どちらの難易度もHP・アーマー・初期弾薬・グレネード満タンで開始します。

## セットアップと開発手順

### 前提条件

- **Node.js**: `>= 22.13.0`
- **パッケージマネージャー**: `npm`

### リポジトリのクローンと起動

```bash
# クローン
git clone https://github.com/username/astrafloor.git
cd astrafloor

# 依存パッケージのインストール
npm install

# ローカル開発サーバー起動
npm run dev
```

ブラウザで [http://localhost:3000](http://localhost:3000) を開き、画面をクリックしてポインターをロックするとゲームが開始されます。

### 自動テストの実行

```bash
# 全136件のユニットテストを実行
npm test
```

### 型検査とプロダクションビルド

```bash
# TypeScript型検査
npx tsc --noEmit

# 本番ビルド（SSR, RSC, Cloudflare Workerの生成）
npm run build
```
