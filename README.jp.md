## ゲーム概要

**Astra Floor** は、PCのキーボード・マウス専用に設計された、シングルプレイヤー向けの3DゾンビサバイバルFPSです。  
プレイヤーは隔離された終末工業地帯を舞台に、迫り来る異能変異体「Zod」の大群を殲滅しながら生き延びるウェーブ制の戦闘に挑みます。各Waveで敵を全滅させてクリアし、Wave間の補給ショップで武器の購入・強化と、弾薬・アーマー・消耗品の補充を行います。Wave 1〜6の猛攻を耐え抜き、Wave 7の最終ボス **Hans Volter** を撃破するとゲームクリア（勝利）、HPが0になるとゲームオーバー（敗北）となります。

※セーブ機能はなく、ブラウザの再読み込みやリトライ、タイトルへ戻ると進行状況はリセットされます。

## 主な特徴

- **ブラウザ完結の本格3D FPS**  
  **Three.js** と **React 19 / vinext** により、追加のクライアントインストールやプラグインなしで、WebGL対応のPCブラウザ上で3Dアクションが動作します。
- **コードで生成するモデルと同梱PBRテクスチャ**\
  銃器モデル、工業地帯の背景建築、敵の形状はコードで生成します。床・壁には `public/textures/environment/` の2048×2048テクスチャ（アルベド・ノーマル・ラフネス）、敵には `public/textures/enemies/` の同梱テクスチャを読み込みます。読み込み前や失敗時には128〜256pxの手続き型テクスチャを使用します。素材はゲーム自身のサーバーから配信し、プレイ中に外部素材サイトへアクセスすることはありません。[床・壁素材のクレジット](public/textures/environment/README.md)も参照してください。
- **Web Audio APIによる効果音合成と同梱BGM**\
  戦闘・銃器の効果音、敵の声、Sirenの絶叫は、Web Audio APIのオシレーター、ノイズバッファ、フィルター、コンプレッサーで合成します。BGMは同梱の `public/audio/zombgm.ogg` を出撃後にループ再生します。音符ボタンでBGMを切り替え、スピーカーボタンで音声全体をミュートできます。
- **出撃前の武器準備**\
  H1・G18C・AR-2・SR-3・RPG-7・Katanaの全6モデルと描画用の資源を、通常・デバッグ出撃前に準備します。完了までは開始ボタンに **INITIALIZING...** と表示します。
- **リアルなリコイルと精密射撃**  
  発砲ごとに強力な反動が加わります。プレイヤー自身のマウス引き下げ操作（リコイルコントロール）が必須です。全銃器およびロケット直撃において、ヘッドショット時は致命的ダメージを与えます。

## ゲームの基本システム・操作

FPS初心者がキーボード操作に慣れやすいよう、操作キーはシンプルかつ一般的なPC FPSと共通の配置を採用しています。

**ヘッドショットのダメージは通常の3倍です。** 銃弾およびRPG-7のロケット直撃で敵の頭部を狙うと、より効率よく敵を倒せます。

### 操作キー一覧（PCキーボード・マウス専用）

| 操作 | キー / 入力 | 概要 |
|---|---|---|
| **移動** | `W` `A` `S` `D` | 全方向の歩行移動 |
| **視点移動 / 照準** | `マウス` | ポインターロックによる視点操作・リコイル制御 |
| **射撃** | `左クリック` | 所持武器のセミオート / フルオート射撃 |
| **照準（ADS / スコープ）** | `右クリック長押し` | 弾の拡散と反動を抑制、スナイパーライフルは5倍スコープ展開 |
| **スプリント（ダッシュ）** | `左Shift` | スタミナ毎秒20消費（ADS中は使用不可） |
| **ジャンプ** | `Space` | 移動中・静止中に跳躍 |
| **リロード** | `R` | マガジン弾薬の再装填 |
| **武器切り替え** | `1` `2` `3` `4` | `1`: ハンドガン/G18C、`2`: アサルトライフル、`3`: スナイパーライフル、`4`: RPG-7 |
| **近接攻撃** | `V` | 通常殴り（初期） / カタナ薙ぎ払い（換装後） |
| **グレネード投擲** | `G` | 放物線投擲。投擲から1.0秒後に爆発（自爆あり） |
| **Medical Kit使用** | `Q` | HPを50即時回復（クールダウン8秒、最大3個所持） |
| **ポーズ（一時停止）** | `Esc` | ポインターロック解除、戦闘・タイマーを一時停止（**RESUME COMBAT** で再開） |
| **Waveクリア進行** | `Space` / `Enter` | リザルト画面から補給ショップ画面へ移行 |
| **デバッグ設定** | タイトル画面で `F8` | 難易度・開始Wave・所持金・最低HP 1の設定 |

### ゲームの進行と補給ショップ

1. **戦闘ウェーブ**：出現するZodの大群を全滅させるとウェーブクリアとなります。
2. **HPの自動全快**：ウェーブクリア時にHPが100まで全回復します。ただしアーマー・弾薬・消耗品は自動回復しません。
3. **補給ショップ（PREPARATION SHOP）**：
   - 敵の撃破やWaveクリア報酬としてクレジット（₡）を獲得します。
   - ウェーブ間は時間制限のないショップで、武器の購入、武器アップグレード、弾薬補給、アーマー、Medical Kit、グレネードを購入できます。
   - 購入した装備、強化段階、所持クレジット、残存する補給品はすべて次のWaveへ引き継がれます。
   - 準備が整ったら **NEXT WAVE**（Wave 7突入時は **FACE FINAL BOSS**）を押して出撃します。

アーマーは残量の範囲で被ダメージを吸収します。ただし、Sirenの絶叫はアーマーを無視してHPに直接ダメージを与えます。一時停止中は戦闘を止め、ポーズメニューの背景にゲーム画面を保持します。

タイトル画面の **F8** でデバッグ設定を開けます。難易度、開始Wave 1〜7、初期所持金₡0〜30,000（₡1,000刻み、初期値₡15,000）を選択できます。**INVULNERABILITY** を有効にするとHPが1未満になりません。デバッグ出撃では、選択したWaveの前に補給ショップを開きます。

## 生き延びるための基本戦術

- **移動撃ちとKatanaによる包囲突破**  
  移動しながら射撃するストレイフ撃ちや、移動中のKatana攻撃（ショップ購入後`V` キー）でゾンビの包囲を切り抜けるテクニックが不可欠です。
- **突進はスプリントでかわす**  
  敵に囲まれたり突進されたりした場合は、立ち止まらずにスプリント（`左Shift`）でかわしましょう。
- **精密なリコイル制御とヘッドショット**  
  ヘッドショットを積極的に狙いましょう。連射時の跳ね上がり反動は手動でマウスを引き下げて抑え込みます。
- **SR-3 Sniper Rifleで貫通を狙う**  
  SR-3 Sniper Rifleは最大3体まで貫通します。厄介な敵や密集した敵をヘッドショットでまとめて倒しましょう。
- **グレネードやMedical Kitを惜しまず使う**  
  グレネード（`G`）やMedical Kit（`Q`）はショップで安く補充できるため、ピンチを待たずに惜しみなく使いましょう。
- **Freshpoundの突進とScrakeの発狂に注意**\
  Wave 5〜6のFreshpoundは、周期的に予兆を出してから突進します。遮蔽物を使うか、突進経路から離れましょう。Scrakeは生存中に残りHPが10%以下になると通常時の3.5倍の速度で走り、死亡するまで発狂し続けます。
- **Sirenの絶叫は遮蔽物で防ぐ**\
  Wave 4〜6のSirenは絶叫だけで攻撃します。0.3秒の予兆後、半径8.7mの赤いエフェクト内に1.5秒間、毎秒20ダメージ（Normal）／27ダメージ（Hard）を与え、アーマーを無視します。範囲から離れるか、遮蔽物で射線を切りましょう。

## 難易度設定

| 難易度 | 開始地点 | 初期所持金 | 特徴 |
|---|---|:---:|---|
| **Normal（通常）** | Wave 1 戦闘開始 | ₡500 | 通常敵のHP・攻撃力・速度・出現数・出現間隔は標準設定 |
| **Hard（ハード）** | Wave 1クリア済みショップ（Wave 2出撃準備） | ₡2,000 | 通常敵のHP・攻撃力1.35倍、速度1.1倍、各Waveの敵数2倍、出現間隔短縮。Wave 2前に装備を整えて開始 |

※どちらの難易度もHP 100・アーマー100・初期弾薬満タン・グレネード3個・Medical Kit 3個で開始します。通常敵のHP・速度には、さらにWave進行による補正が加わります。

## セットアップと開発手順

### 前提条件

- **Node.js**: `>= 22.13.0`
- **パッケージマネージャー**: `npm`

### リポジトリのクローンと起動

```bash
# クローン
git clone https://github.com/BEROCHLU/astrafloor.git
cd astrafloor

# 依存パッケージのインストール
npm install

# ローカル開発サーバー起動
npm run dev
```

開発サーバーが表示したURL（既定は [http://localhost:3000](http://localhost:3000)）をブラウザで開きます。**INITIALIZING...** の終了後に難易度を選んで **DEPLOY** を押してください。Normalでは戦闘開始時にポインターをロックし、Hardでは先に補給ショップを開きます。

### 自動テストの実行

```bash
# 自動テストを実行
npm test
```

### 型検査とプロダクションビルド

```bash
# TypeScript型検査
npx tsc --noEmit

# 本番ビルド（SSR, RSC, Cloudflare Workerの生成）
npm run build

# ビルド済みWorkerをローカルでプレビュー（ビルド成功後）
npm start
```

本番配信は[Cloudflare用ワークフロー](.github/workflows/deploy-cloudflare.yml)で設定しています。`main` へのpushまたは手動実行時に、`DEPLOY_TARGET=cloudflare` を設定してビルドし、`dist/server/wrangler.json` を使ってデプロイします。
