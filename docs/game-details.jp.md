# Astra Floor — 詳細ルール・開発資料

日本語 | [English](game-details.md) | [基本ルール](../README.jp.md)

工業地帯の封鎖区域でゾンビの襲撃を生き延びる、シングルプレイヤーの3D FPSです。敵の撃破とウェーブクリアで得たクレジット（₡）を使い、武器の購入・強化と消耗品の補充を行います。

仕様の基準は現在のコードです。[ゲーム本体](../lib/game.ts)、[Siren](../lib/siren.ts)、[Hans Volter](../lib/hans.ts)、[画面UI](../app/page.tsx)の実装に沿って記載しています。

## 勝利・敗北と進行

- ウェーブ内の敵を全滅させるとクリアし、HPが100まで全回復します。
- 通常・ハードともにウェーブ1〜6のクリア報酬が **₡250 + ウェーブ数 × ₡50** です。クリア画面からショップへ進めます（ハードの開始時は従来どおりウェーブ1の戦闘をスキップ）。
- ショップには時間制限がありません。**NEXT WAVE** を押すと次のウェーブを開始します。
- 通常・ハードともにウェーブ6の後にショップを挟み、ウェーブ7の最終ボス **Hans Volter** を倒すと勝利します。HPが0になると敗北します。
- ウェーブ間では所持金、購入済みの装備、強化段階、弾薬、アーマー、グレネード、Medical Kitの残数を引き継ぎます。クリア時に自動回復するのはHPです。
- セーブ機能はありません。ページの再読み込み、リトライ、タイトルへの帰還で進行と購入状態がリセットされます。

PCのキーボード・マウス専用です。ゲーム内UIは英語で、マルチプレイヤーとタッチ操作には対応していません。

Hans Volterは専用の固定値（通常15,000 / ハード20,000）を使用し、通常敵のウェーブ・難易度倍率を重ねません。

## 操作

### デバッグ設定パネル

タイトル画面で **F8** を押すとデバッグ設定パネルを開閉します（戦闘中は無効）。難易度、開始Wave 1〜7、初期所持金（初期値₡15,000、₡0〜30,000を₡1,000刻みのスライダーで設定）を選択できます。指定したWaveの直前補給ショップ（PREPARATION SHOP）から開始し、戦闘開始後は通常のゲーム進行を継続します。詳細は「デバッグモード（F8）」を参照してください。

ダッシュはスタミナを消費し（毎秒20消費、非ダッシュ時に毎秒20回復、上限100）、照準中は使えません。戦闘開始時にマウスが固定され、Escで解除すると一時停止します。再開は **RESUME COMBAT**、タイトルへの帰還は **RETURN TO TITLE** です。

移動速度は通常3.7m/秒、ダッシュ6.2m/秒、照準中2.3m/秒です。ジャンプ中も水平移動の障害物判定は有効です。一時停止中は戦闘を止め、ポーズメニューの背景にゲーム画面を保持します。音符ボタンでBGMを切り替え、スピーカーボタンで音声全体をミュートできます。BGMはポーズ・ショップ中も継続します。

## HP・アーマー・Medical Kit

HPとアーマーの上限は、難易度にかかわらず100です。アーマーは残量の範囲で被ダメージを吸収し、吸収しきれなかった分だけHPが減ります。ただし、Sirenの絶叫はアーマーを無視してHPに直接ダメージを与えます。

- **ウェーブクリア**：HPが100まで全回復します。Medical Kitは消費も補充もされません。
- **Qキーの回復**：Medical Kitを1個消費し、HPを50回復します。回復後のHPは最大100です。
- **クールダウン8秒**：使用後は、キットが残っていても8秒間は再使用できません。クールダウンは戦闘中に進み、一時停止・ショップ中は止まります。長押しでの連続消費はありません。
- **初期所持・上限**：全難易度で3個所持して開始し、最大3個まで持てます。
- **補充**：ショップのMedical Kitを₡50で購入すると1個増えます。購入時にHPは回復しません。
- **購入条件**：3個所持していると購入できません。HP満タンでも、所持数が3個未満なら購入できます。
- **使用条件**：戦闘中のみ使用できます。HP満タン時、キットが0個のとき、クールダウン中は消費・回復しません。

HUDの **Q MEDKIT** に現在の所持数・上限と、クールダウン中の残り秒数を表示します。

## 銃・照準・リコイル

ダメージは強化前の基本値、予備弾は弾薬ポーチ未所持時の上限です。

| 武器 | 入手 | 装弾数 / 予備弾上限 | 基本ダメージ | 射撃間隔 / リロード |
|---|---|---|---|---|
| H1 SERVICE PISTOL | 初期装備 | 12 / 48 | 24 | 0.24秒 / 1.35秒 |
| G18C MACHINE PISTOL | ₡750でハンドガンを換装 | 33 / 132 | 22 | 0.068秒 / 1.35秒 |
| AR-2 ASSAULT RIFLE | ₡800で購入 | 30 / 120 | 30 | 0.095秒 / 1.9秒 |
| SR-3 SNIPER RIFLE | ₡1,100で購入 | 5 / 18 | 150 | 1.1秒 / 2.5秒 |
| RPG-7 | ₡4,000で購入 | 1 / 7 | 爆発600 | 0.9秒 / 2.4秒 |

H1・SR-3・RPG-7はクリックごとに1発撃ちます。AR-2とG18Cは左クリック長押しで連射し、短くクリックすれば単発射撃もできます。G18C購入後はそのプレイ中のハンドガンが置き換わり、武器キーは1のままです。

フルオート射撃はマガジンが空になると停止します。予備弾があれば、Rキーまたは再クリックでリロードできます。各武器スロットの弾数は独立して保持します。

銃のヘッドショットは3.0倍のダメージです。SR-3の弾は最大3体を貫通します。銃弾は遮蔽物で止まります。

### 照準と反動

腰だめ撃ちでは弾が拡散し、特にSR-3のノースコープ射撃は大きく散ります。右クリックでH1・G18C・AR-2・RPG-7はアイアンサイト、SR-3は約5倍のスコープを使います。照準中は拡散と反動が小さくなり、SR-3のスコープ射撃ではランダムな拡散がなくなります。

発砲のたびに視点へ上下・左右の反動が加わります。**射撃を止めても照準は自動で元に戻りません。** マウス操作で反動を制御します。G18Cの視点反動・モデル後退量はAR-2より20%大きくなります。銃モデルの後退・揺れは自動で戻り、ADS中はモデルの動きとマズルフラッシュも抑えます。

### SR-3のボルトアクション

次弾が残っていれば、射撃後にスコープを下げ、約1.1秒かけてボルトを操作します。完了するまでは次弾を撃てず、武器の持ち替えでも省略できません。持ち替え中は未完了のボルト操作を保持し、SR-3を再装備すると続きから進めます。右クリックを押し続けていれば、操作後にスコープへ戻ります。ボルト操作中にRを押すと、操作完了後にリロードします。マガジンが空になった場合はボルト操作は発生せず、即座にリロードや空撃ちが可能です。

### RPG-7のロケット

₡4,000で購入すると直ちに装備し、以降は戦闘中の **4キー** で切り替えられます。装弾数は1発、予備弾は7発（Ammo Pouch購入後は11発）です。アイアンサイトを使用し、スコープ・ボルト操作・貫通はありません。発射時や空の状態で再装備した際、予備弾があれば自動的にリロードを開始します。

- ロケットは照準方向へ60m/秒で直進し、重力では落下しません。敵・壁・地面に着弾するか、飛行時間が2秒に達すると一度だけ爆発します。
- 敵への基礎爆発ダメージは600。グレネードの2倍で、同じく半径7m未満、距離減衰は「基礎ダメージ × (1 − 距離 / 9)」、遮蔽物で遮られます。距離は爆心地から敵の位置に高さ1mを加えた点まで測ります。
- ロケットが敵の頭部（head）へ直撃した場合は、直撃した敵の爆発ダメージだけが3.0倍（距離減衰前の上限1,800）になり、専用音とHEADSHOT表示が発生します。頭部への直撃は、低い遮蔽物が胴体中心への射線を遮っていても有効です。周囲の敵への通常の爆風には遮蔽物判定を行います。
- 直接弾丸ダメージやショップのダメージ強化は適用しません。Hansの停止中の被ダメージ倍率は有効です。
- 自爆ダメージはグレネードと同じで、半径7m未満に `round(75 × (1 − プレイヤーまでの距離 / 7))` を与え、遮蔽とアーマーを考慮します。
- 一時停止中は飛行と起爆タイマーも停止します。勝敗確定・ショップ移動・タイトル帰還・リトライで飛翔中のロケットを消去します。
- 低い発射音と専用の反動があり、照準は自動では戻りません。弾薬補給とAmmo Pouchによる補充も有効です。

## 近接攻撃とカタナ

| Vキーの攻撃 | 基本ダメージ | リーチ | 攻撃間隔 | 特徴 |
|---|---|---|---|---|
| 通常の近接攻撃 | 42 | 2.9m | 0.65秒 | 初期能力。リーチ2.9mの殴打攻撃。弾薬節約や瀕死Zodのトドメに有効 |
| カタナ | 100 | 3.9m | 0.8秒 | リーチ3.9m。左から右へ真横に振り抜く水平扇状薙ぎ払いで前方複数の敵を一掃 |

カタナは₡1,000で購入すると、**そのプレイ中のVキーの攻撃を永久に置き換えます**。元の近接攻撃には戻せません。銃の装備を維持したまま使え、武器切り替えキーは増えません。
- **モーションと判定**：画面左側での抜刀・構え（予兆）から、照準中央の高さを完全な真横に左から右へと水平に薙ぎ払う扇状スラッシュ（水平アーク）を描きます。前方扇状の有効範囲（3.9m）にいる複数の敵を一度に切り裂きますが、薄い壁などの遮蔽物は貫通しません。
- **命中のタイミング**：ダメージ判定はVキーで攻撃を開始したときに1回行います。見た目の薙ぎ払いで追加の連続ダメージは発生しません。
- **射撃との排他制御**：カタナを振っている間は銃のフルオート射撃が一時的にブロックされ、スイング完了後に自動的に射撃が再開されます。

## グレネード

Gキーで手を振りかぶり、照準方向へ投げます。黄色い帯の付いた弾体は放物線を描いて飛び、地面や壁で跳ね、手を離れてから約1秒後に爆発します。

- 投擲モーションは0.55秒で、開始0.20秒後に手から離れます。初速は照準方向へ15m/秒に上向き2.8m/秒を加え、重力加速度は12m/秒²です。
- 爆発は周囲7m未満への範囲攻撃で、敵へのダメージは `300 × (1 − 距離 / 9)`。遮蔽物に遮られ、距離が離れるほど威力が減衰します。
- **プレイヤーへの自爆ダメージ**：爆心地から7m未満で `round(75 × (1 − プレイヤーまでの距離 / 7))` の自爆ダメージを受け、アーマー残量の範囲で優先吸収します。壁などの遮蔽物に隠れている場合はダメージを受けません。
- 投擲中は照準を下げ、射撃・近接攻撃・武器切り替えを一時的に制限します。
- 初期所持数・所持上限は全難易度で3個です。Ammo Pouch購入後は上限が2個増え、全難易度で5個になります。ショップで₡50を支払うと1個補充できます。
- 一時停止中は投擲モーション・飛行・起爆タイマーも止まります。
- ショップのダメージ強化はグレネードには適用されません。

### 弾薬ポーチ（Ammo Pouch）

- **予備弾数拡張**：全武器の予備弾上限を基本値の+50%に引き上げます。
  - **H1**：48発 → 72発
  - **G18C**：132発 → 198発
  - **AR-2**：120発 → 180発
  - **SR-3**：18発 → 27発
  - **RPG-7**：7発 → 11発
- **グレネード上限拡張**：Frag Grenadeの所持上限が3個から5個へ増加。
- **即時全回復**：購入時に全武器の装填弾・予備弾およびグレネードを増加後の上限まで即時満タン回復します。以降の弾薬補給（₡100）やグレネード購入（₡50）も増加後の上限まで補充されます。
- **買い切り**：価格₡1,000で1プレイ中1度のみ購入可能。そのランの全Waveに引き継がれます。

### 武器アップグレード（Weapon Upgrade）

- **段階と価格**：
  - **第1段階（Lv.1）**：₡1,000（ダメージ+35%、基本値の **1.35倍**）
  - **第2段階（Lv.2）**：₡2,000（ダメージ+70%、基本値の **1.70倍**）
  - 最大2段階。Lv.2到達後はショップ表示が `MAX LEVEL` となり再購入不可となります。
- **ダメージ計算式**：
  $$\text{与ダメージ} = \text{基礎威力} \times (1 + \text{強化段階} \times 0.35) \times (\text{ヘッドショット} \, ? \, 3.0 : 1.0)$$
- **適用対象と仕様**：
  - **銃弾射撃**：H1（24 → 32.4 → 40.8）、G18C（22 → 29.7 → 37.4）、AR-2（30 → 40.5 → 51.0）、SR-3（150 → 202.5 → 255.0）の直撃銃弾すべてに適用。
  - **近接攻撃**：初期近接パンチ（42 → 56.7 → 71.4）およびカタナ（100 → 135 → 170）の双方に適用。
  - **ヘッドショット乗算**：3.0倍のヘッドショット倍率と重複して乗算されます（例: SR-3で頭部命中時、Lv.0で450、Lv.1で約608、Lv.2で765ダメージ）。
  - **爆発物への適用外**：RPG-7のロケット爆風ダメージおよび手榴弾の爆風ダメージには適用されません（固定値）。

所持金不足、購入済みの装備、所持上限に達した補給品、強化上限に達した商品は購入できません。

| Husk | 3 | 240 | 28 | ₡160 | 右腕のキャノン砲で攻撃する遠距離型 |
| Siren | 4 | 150 | 毎秒20 | ₡120 | 拘束具の痩身型。半径8.7mにアーマーを無視する音波悲鳴を放つ |
| Freshpound | 5 | 3,000 | 42 | ₡450 | 回転ドリルと周期的な高速突進 |
| Hans Volter | 7 | 15,000（通常） / 20,000（ハード） | 攻撃ごとに異なる | ₡2,000 | 二丁ライフル、毒ガス、跳躍斬撃、エネルギー切れ |

### 遠距離攻撃

- **Bloat**：約0.8秒の予備動作後、弾速20m/秒の飛沫を発射します。射撃距離は3〜19mです。
- **Husk**：約0.9秒間砲口がオレンジ色に光り、弾速60m/秒の高速弾を発射します。射撃距離は4〜27mです。

どちらも予備動作中に狙いを固定するため、横移動や遮蔽物を使って回避できます。

### Sirenの音波悲鳴

ウェーブ4〜6に出現します（通常：2 / 3 / 4体、ハード：2 / 4 / 4体）。
- **出現置換ローテーション**：Bloat → Husk → Scrake → その他（Clot/Gorefast/Crawler）の順に1体ずつローテーションして置換します。該当する敵種が不足している場合はその他枠から代替置換し、Freshpoundは完全に保護されます。
- **予兆と発動**：プレイヤーが半径8.7m以内にいて、遮蔽物・高さ判定を満たすと移動を停止します。0.3秒の予兆後に1.5秒間叫び、3.0秒間のクールダウンに入ります。予兆・絶叫中は移動を止め、クールダウン中もプレイヤーへ悲鳴が届く場合は停止を続けます。範囲外や遮蔽物の裏に移った場合は追跡を再開できます。赤い範囲エフェクトはHansの緑色の毒ガスと同じ実装を使います。
- **アーマー100%貫通**：毎秒20ダメージ（通常：1回の悲鳴で計30HP）/ 毎秒27ダメージ（ハード：他の通常敵と共通の1.35倍補正、1回の悲鳴で計40.5HP）を、**アーマーを全無視してプレイヤーHPに直接与えます**。
- **遮蔽物と視線判定**：壁や障害物に遮られている場合、またはプレイヤーの視点の高さが3.4mを超える場合は、新たなダメージの蓄積を止めます。それまでの曝露分は、次の0.25秒の判定または絶叫終了時に与えます。範囲から離れても予兆・絶叫のタイマーは継続します。複数体の悲鳴は重複してダメージが加算されます。近接殴り攻撃は行いません。

### Scrakeのチェーンソー

攻撃のリーチは3.9m、基本ダメージは30、攻撃間隔は1.15秒です。通常時は約0.3秒かけてチェーンソーを振り上げ、横薙ぎに振り、構え直します。

生存中に被ダメージで出現時の最大HPの10%以下になると、溜め動作なしで即座に瀕死発狂します。最大HPにはウェーブ・難易度の補正を含み、致死ダメージでは発狂せず死亡します。発狂中はウェーブ・難易度補正を含む通常時の3.5倍の速度で、既存の障害物回避を使って追跡します。近接射程内でも追跡を続け、接触距離ではプレイヤーを通り抜けないよう移動を制限します。

上体を前傾させ、脚の走行モーションとチェーンソーの大きな左右の振り回しを接触中も継続します。攻撃ダメージ・間隔・射程と既存の遮蔽・高さ判定は維持し、振り回すたびの追加ダメージはありません。発狂は死亡まで永続し、時間切れでは解除されません。一時停止中は移動・攻撃・モーションが停止し、再開後も発狂状態を維持します。Freshpoundの周期的な発狂とは独立した動作です。

### Freshpoundの突進

通常のドリル攻撃のリーチは3.0mです。10秒間の通常行動後、胸を赤く点滅させて1秒間咆哮し、通常移動の10倍速で最大3秒間突進します。

咆哮終了時に進行方向を固定し、突進中は追尾せず、進路上の他の敵を押しのけます。突進時の攻撃距離は2.8mで、壁への衝突、プレイヤーへの命中、制限時間のいずれかで終了します。その後は再び10秒間の通常行動に戻ります。一時停止中は突進までのタイマーも止まります。

通常・ハードともにウェーブ5の開始時に1体、ウェーブ6の開始時と中盤に計2体出現します。

### Hans Volter：最終ボス

通常・ハードともにウェーブ6クリアでHPが全回復し、₡550のクリア報酬を獲得します。ショップで補給して **FACE FINAL BOSS** を押すと専用戦を開始します。雑魚の追加出現はありません。既存の装備・強化・消耗品を引き継ぎます。

ボスのモデルは青白い肌、黒いガスマスク、緑の発光配管と胸部コア、大きな背面タンク、赤褐色のベルト、黒い脚部装備、注射針状の爪を持ちます。射撃時はMKb42風ライフルを二丁構え、それ以外の行動では腰側に収納します。

| 行動 | 仕様と対処 |
|---|---|
| 跳躍斬撃（超大跳躍） | 距離3m未満、または行動選択ローテーション4枠目で25m以内のときに選択。0.7秒の構え後、方向を固定して跳躍。移動距離3.8〜29mに応じて継続時間0.26〜0.88秒、高さ1.1〜3.5mを決め、速度は移動距離÷継続時間。水平方向3.5mの斬撃判定で30 / 34 / 38ダメージを1回だけ与え、高さ・遮蔽物も判定する。後退だけでは捕まる場合があり、横移動や遮蔽物で回避する。壁で停止 |
| 毒ガスグレネード | 1秒の投擲予備動作から緑色の弾体を2発、最終段階では3発投げる。投げてから1.4秒で起爆。半径4.2mに6秒残り、毎秒24 / 30 / 36ダメージ。地面の緑の輪から離れる。重なったガスは加算されず、遮蔽物がダメージを遮る |
| 二丁MKb42射撃 | 32m以内で選択。0.85秒の構え後、左右交互に2.4秒間連射。最大18 / 20 / 22発、射撃間隔0.125 / 0.110 / 0.095秒。1発5ダメージ、弾速80m/秒。プレイヤーの現在位置を追い、わずかなランダム拡散を加える。弾は遮蔽物で止まる |
| 高速移動 | 0.5秒の予兆から0.65秒のダッシュ。速度18 / 19.8 / 21.6m/秒。遠距離では接近、近距離では横へ回避。壁は通り抜けない |
| エネルギー切れ | エネルギー100から、時間経過で毎秒1、射撃18、ガス22、ダッシュ12、跳躍20を消費。0になると実行中の攻撃終了後に4秒停止し、受けるダメージが1.5倍になる。停止終了後は100へ充電して再開 |

数値を3つ併記したものは行動段階1 / 2 / 3の順です。HP65%以下で段階2、30%以下で段階3へ移り、連射速度と近接・ガス攻撃が強まります。画面上部にHP・エネルギー・行動段階・攻撃予告を表示します。ヘッドショットと武器強化は通常どおり有効です。

追跡速度は段階1 / 2 / 3で6.24 / 6.48 / 6.72m/秒です。攻撃値には両難易度ともボス専用の設定を使い、通常敵のHard補正1.35倍は加えません。重なった毒ガスは、その場で有効な最大ダメージを使い、加算しません。毒ガスのダメージはアーマーで吸収できます。

一時停止中は攻撃、移動、毒ガス、グレネードのタイマーも止まります。撃破・敗北・タイトル帰還・リトライでは毒ガスと敵の弾を消去します。

Hansはエネルギー消費と一時停止の仕組みを使用します。掴み吸血・自己回復・シールド・増援召喚は実装していません。HP（通常15,000 / ハード20,000）や攻撃値は本作のシングルプレイヤー用に設定しています。

## デバッグモード（F8）

タイトル画面で **F8キー** を押すと、デバッグ設定パネルの有効/無効を切り替えられます（戦闘中は無効）。

- **開始Wave選択**：
  - NORMAL・HARDともにWave 1〜7（Wave 7: Hans Volter専用ボス戦）を選択可能。画面の初期選択はWave 1です。
- **開始所持金設定**：
  - 画面の初期値は₡15,000。範囲は₡0〜30,000です。
  - スライダーで₡1,000刻みに設定します。
- **HP下限設定（チェックボックス）**：
  - 「PREVENT DEATH (MIN HP 1)」にチェックを入れると、敵の攻撃・自爆・毒ガスなどのダメージを受けてもHPが1を下回らなくなり、死亡（ゲームオーバー）せずに戦闘を継続できます。
- **Wave開始前の補給画面（PREPARATION SHOP）**：
  - どのWave（Wave 1を含む）から開始しても、戦闘突入前に補給ショップ画面（ヘッダー: `WAVE 0N PREPARATION`）が開きます。
  - 所持金を使って好みの武器・弾薬・アーマーを整えた後、`START WAVE N`（Wave 7時は `FACE FINAL BOSS`）ボタンを押すことで指定したWaveの戦闘を開始できます。
  - 戦闘開始以降は通常のゲーム進行（Waveクリア報酬、次Waveへの補給、勝利/敗北）を継続します。

ゲーム内部の `Game.start()` APIは、画面とは別に `debugCash` を₡0〜999,000へ制限し、省略時には₡20,000を使います。これはタイトル画面のスライダーの初期値・上限ではありません。タイトルのバージョン表記は `app/page.tsx` に直接記載し、`package.json` とは連動しません。

## 技術スタックと内部アーキテクチャ

モデルと背景の形状はコードで生成します。床・壁・敵のテクスチャとBGMは同梱ファイルをゲーム自身のサーバーから読み込みます。

- **フロントエンド / レンダリング**: React 19.2、Vite 8、vinextのNext.js互換App Router。実行時の依存は `vinext` で、アプリケーションの依存関係にNext.js本体はありません。
- **3Dグラフィックス**: Three.js (`r185`)
  - 銃器・敵・弾丸・背景の形状を生成し、モデルの固定部品を結合、背景をインスタンスでまとめて描画します。
  - 床・壁は `public/textures/environment/` の2048×2048アルベド・ノーマル・ラフネス画像、敵は `public/textures/enemies/` の共有画像を読み込みます。
  - 読み込み前や失敗時には128〜256pxの手続き型 `DataTexture` を使用します。[床・壁素材のクレジット](../public/textures/environment/README.md)も参照してください。
- **音響エンジン**: Web Audio API
  - 銃声、ボルト・リロード音、敵の声、Sirenの絶叫などをオシレーター・ノイズバッファ・フィルター・コンプレッサーで合成します。
  - BGMは `public/audio/zombgm.ogg` をループ再生し、効果音と共通のマスター音声経路へ接続します。
- **リコイル・弾道物理**:
  - 発砲ごとのカメラピッチ・ヨーへの手動補正型リコイル（自動中心復帰なし）。
  - レイキャスト判定による多重部位ヒット優先度（突き出した腕よりも頭部Head判定を最優先）。
- **デプロイ・ランタイム**: Cloudflare Workers（`@cloudflare/vite-plugin`、Wrangler）。`DEPLOY_TARGET` が `cloudflare` 以外の場合はSitesプラグインも有効です。[本番CI](../.github/workflows/deploy-cloudflare.yml)は `DEPLOY_TARGET=cloudflare` でビルドし、`dist/server/wrangler.json` を使って配信します。Markdown・MDX・`docs/` だけの更新はスキップし、`main` での手動実行は可能です。

### 資源の事前準備と最適化

- 通常・デバッグ出撃前に `Game.prepareResources()` をゲームインスタンスごとに1回実行します。全6武器をキャッシュし、実ゲームのシーンを使って描画プログラムを準備、32×32の画面外描画で形状・テクスチャをGPUへ転送します。失敗時も描画状態を復元して一時描画先を解放します。成功まで `INITIALIZING...` を表示し、失敗時は出撃できません。H1とG18Cは仕上げ材質と粒状テクスチャを共有し、装備モデルの位置・アニメーション状態は独立します。
- 経路探索は61×61マスの通行可否をキャッシュし、探索キューと距離配列を再利用します。確認間隔は0.55秒で、プレイヤーの四捨五入した所属マスと障害物情報が変わらなければ探索を省略します。マップ再構築時にキャッシュを無効化します。
- 敵を2m四方の区画に登録し、押し合いとFreshpoundの押しのけでは周囲9区画を調べます。敵配列の処理順を維持し、移動・押しのけ・死亡後に登録を更新します。
- HUDは `GameUiStore` と `useSyncExternalStore` を使い、各表示に必要な値だけを購読します。Snapshotの通知周期は約0.06秒を維持し、無関係な経過時間・FPSの変化では画面全体を再描画しません。
- 描画は `requestAnimationFrame` を使い、独自の90 FPS上限は設けていません。ピクセル比の上限は1.75、平行光源のシャドウマップは2048×2048です。

## 開発・テスト・ビルド検証

Node.js `>=22.13.0` とnpmを使用します。コマンドは [package.json](../package.json) で定義しています。開発サーバーが表示したURL（既定は `http://localhost:3000`）を開き、武器準備の完了後に **DEPLOY** を押してください。Normalは戦闘を開始し、Hardは先にWave 2の準備ショップを開きます。

```bash
# ローカル開発サーバー起動
npm run dev

# 自動テストを実行
npm test

# TypeScript 型検査
npx tsc --noEmit

# プロダクションビルド（Cloudflare Worker / SSR / クライアントアセット）
npm run build

# ビルド成功後、生成済みWorkerをローカルでプレビュー
npm start
```
