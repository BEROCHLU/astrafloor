# DEADSHIFT — ゲームルール

日本語 | [English](game-rules.md)

PCのキーボード・マウス専用の、シングルプレイヤー向けゾンビサバイバルFPSです。

## 目的

各Waveで敵を全滅させ、Wave間のショップで補給しながら進みます。Wave 7の最終ボスを倒すとゲームクリア（勝利）、HPが0になるとゲームオーバー（敗北）となります。

**Normal** はWave 1から戦闘が開始します。**Hard** は敵が強化・高速化され、Wave 2から始まります（初期所持金₡2,000の補給ショップから始まり、装備を整えてからWave 2へ出撃）。なおセーブ機能はなく、ページの再読み込みやリトライ、タイトルへ戻ると進行状況はリセットされます。

## 操作

FPSの初心者がキーボード操作に慣れるよう、操作キーを少なくして他のFPSと共通の操作感となるように意識している。移動撃ちや、移動中の近接攻撃（Vキー）を使ってゾンビの集団を切り抜けるテクニックを駆使しないとクリアは難しい。

| 操作 | 入力 |
|---|---|
| 移動 / 視点移動 | W A S D / マウス |
| 射撃 / 照準（ADS） | 左クリック / 右クリック長押し |
| スプリント / ジャンプ | 左Shift / Space |
| リロード | R |
| ハンドガン / アサルトライフル / スナイパーライフル / RPG-7 | 1 / 2 / 3 / 4（所持武器のみ） |
| 近接攻撃（Vキー） | V |
| グレネード投擲 | G |
| Medical Kit使用 | Q |
| 一時停止（ポーズ） | Esc |
| Waveクリア後に進む | Space / Enter |

ポーズからの再開は **RESUME COMBAT** を選択します。スプリントはスタミナを消費し、照準（ADS）中は使用できません。

## 生き延びるために

- HPとアーマーの上限は各100です。受けたダメージはアーマーが優先して吸収します。
- Waveクリア時にHPが全回復します。アーマー、弾薬、消耗品（Medical Kit・グレネード）はショップで購入して補充します。
- Medical Kit（Qキー）はHPを50回復し、使用後は10秒のクールダウンが発生します。初期所持数・所持上限はともに3個です。
- グレネードやRPG-7の爆風は自爆ダメージを受けます。至近距離での爆発を避け、距離を取るか遮蔽物を利用しましょう。
- ヘッドショットを積極的に狙い、敵の突進はスプリントでかわして、常に足を止めずに動き続けましょう。射撃後のリコイル（反動）による照準の跳ね上がりは自動で戻らないため、マウスを手動で引き下げて制御（リコイルコントロール）します。

## ショップ

敵の撃破やWaveクリア報酬としてクレジット（₡）を獲得します。ショップでは武器の購入、ダメージ強化、弾薬補給、アーマー、Medical Kit、グレネードを購入できます。ショップに時間制限はありません。準備が整ったら **NEXT WAVE** を押して次のWaveを開始します。

- G18Cを購入すると初期装備のハンドガンが置き換わり、引き続き1キーで使用できます。
- Katana（カタナ）を購入すると、そのプレイ中のVキー近接攻撃が広範囲・高威力の斬撃へ永久に強化されます。
- Ammo Pouch（弾薬ポーチ）を購入すると、全武器の予備弾薬上限とグレネード所持上限が増加し、購入時に全弾薬・グレネードが全回復します。
- 購入した装備、強化段階、所持クレジット、および残存する補給品はすべて次のWaveへ引き継がれます。
